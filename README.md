# Магазин — Telegram Mini App

Ваш бот превращён из чат-бота с инлайн-кнопками в полноценный **Telegram Mini App**
(веб-приложение, открывающееся внутри Telegram по кнопке меню). Весь функционал
исходного `bot.py` объединён в одном веб-интерфейсе на основе вашего `shop.html`:

- каталог категорий/товаров, корзина, покупка;
- оплата **Telegram Stars** — напрямую через `openInvoice`, либо с внутреннего
  баланса (⭐), который тоже пополняется через Stars;
- авто-выдача товара (текст и/или файл) сразу в чат с ботом после оплаты;
- отзывы;
- полная админ-панель: заявки, категории, товары (+ авто-выдача), настройки,
  админы, пользователи (бан/баланс), рассылка.

Оплата рублями по скриншоту убрана — макет `shop.html` был рассчитан только на
оплату ⭐, и это заодно избавляет от ручной модерации: платежи Stars подтверждаются
автоматически.

## Структура

```
webapp/
  server.py         — Flask-бэкенд: отдаёт сам Mini App и весь REST API
  database.py        — тот же SQLite-слой, что и в исходном боте (shop.db)
  telegram_api.py     — обёртка над Telegram Bot API (сообщения, файлы, счета Stars)
  auth.py             — проверка Telegram.WebApp.initData
  bot_setup.py         — разовый скрипт: ставит вебхук и кнопку меню
  config.py / .env      — настройки (токен, админы, домен)
  static/index.html      — сам Mini App (ваш дизайн из shop.html, но с реальными данными)
  shop.db                — ваша существующая база (перенесена как есть)
  uploads/delivery/       — файлы автовыдачи, загруженные через админ-панель
```

## Запуск

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Заполните `.env` — токен уже перенесён из вашего `config.py`, но:
   - **`WEBAPP_URL`** — обязательно укажите публичный `https://...` адрес,
     на котором будет доступен сервер (см. ниже про хостинг).
   - Мини-приложениям Telegram **обязательно нужен HTTPS** — по обычному http
     Telegram его не откроет.
3. Запустите сервер:
   ```
   python server.py
   ```
   (для продакшена — `gunicorn -w 2 -b 0.0.0.0:5000 server:app`)
4. Один раз выполните (и повторно — если поменяли домен):
   ```
   python bot_setup.py
   ```
   Это ставит боту вебхук `WEBAPP_URL/api/telegram/webhook` (туда прилетают
   события оплаты Stars) и кнопку меню, открывающую Mini App.

### Про домен

Нужен реальный HTTPS-адрес, за которым видно ваш `server.py`. Варианты:
- любой VPS/хостинг с доменом + Nginx (проксирующий на `127.0.0.1:5000`) + Let's Encrypt;
- для теста — временный туннель, например `ngrok http 5000` (даёт временный
  `https://xxxx.ngrok-free.app`, который и указываете в `WEBAPP_URL`).

Открыть Mini App можно только из Telegram (кнопка меню бота, `/start`) — так
Telegram передаёт `initData`, по которой сервер проверяет, что это правда вы.
Открытие `index.html` напрямую в браузере не авторизуется (кроме
`ALLOW_DEV_NOVALIDATE=1` для отладки — см. ниже).

### Локальная отладка без Telegram

Если `ALLOW_DEV_NOVALIDATE=1` в `.env` (по умолчанию включено), можно открыть
`http://localhost:5000` в обычном браузере — сервер подставит тестового
пользователя `DEV_USER_ID`. Учтите: платежи Stars (`openInvoice`) при этом
не сработают — это функция самого Telegram-клиента. **Перед реальным запуском
обязательно выставьте `ALLOW_DEV_NOVALIDATE=0`.**

## Как теперь всё работает

- **Покупка/корзина** — кнопка "Оплатить ⭐" создаёт счёт через
  `createInvoiceLink` и открывает его нативным окном Telegram
  (`Telegram.WebApp.openInvoice`). После оплаты Telegram шлёт вебхуку
  событие `successful_payment` — сервер сразу подтверждает заявку и
  отправляет товар (текст/файл) отдельным сообщением в чат с ботом.
- **Оплата с баланса** — если ⭐ на балансе хватает, есть кнопка
  "Списать с баланса" — товар выдаётся мгновенно, без открытия счёта.
- **Пополнение баланса** — тоже через Stars-инвойс; после оплаты
  сумма зачисляется автоматически.
- **Авто-выдача в админке** — при загрузке файла он сохраняется на сервере
  (`uploads/delivery/`), а не как Telegram file_id — так админ-панель не
  зависит от переписки с ботом. При доставке файл отправляется покупателю
  напрямую с диска.
- **Раздел "Заявки"** в админке в основном для истории/ручных случаев —
  Stars подтверждаются сами, вручную подтверждать почти никогда не нужно.

## Безопасность токена

Токен бота уже был в открытом виде в присланном вами `config.py`, и я перенёс
его в `.env` для удобства. Если этот проект попадёт куда-то ещё, кроме вашего
сервера (например, в публичный репозиторий), лучше перевыпустить токен у
@BotFather (`/mybots` → выбрать бота → Bot Settings → API Token → Revoke) и
вписать новый в `.env`.

## Чего нет по сравнению со старым ботом

- Оплата рублями по скриншоту (модерация вручную) — не переносилась, так как
  ваш `shop.html` уже был спроектирован только под ⭐.
- Обычный `bot.py` с инлайн-кнопками больше не нужен — весь интерфейс теперь
  в Mini App; `server.py` сам обрабатывает `/start` через вебхук (присылает
  приветствие с подсказкой открыть меню).
